# OTY pitch animation

A self-playing 90-second visual backdrop for the OTY (Oh, That's Y!) investor pitch, led by the OTY octopus mascot.

- Open `index.html` (or the GitHub Pages link) and press `F` for fullscreen. It starts on load.
- Keys: `Space` pause, `R` restart, `1`-`6` jump to a scene.
- `why-us.html` is the separate "Why us?" founders slide, shown after the pitch (press `F` for fullscreen, `R` to replay).
- `pitch-script.md` has the spoken script, timed to the scenes.
- `assets/octo/` holds the mascot poses. The page already embeds the ones it uses, so it works as a single file.

Views shown are illustrative, from simulated demo data. There are no real-school results yet.
